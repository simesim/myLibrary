# Моя библиотека

Личный онлайн-каталог книг с полками-корешками, поиском, сортировкой, фильтрами по жанру/статусу и кнопкой «наугад с полки». Данные подтягиваются напрямую из Google Таблицы — менять каталог можно прямо в ней, без правок кода.

## 1. Настрой Google Таблицу

Создай таблицу с такими колонками в первой строке (порядок не важен, регистр не важен):

| Название | Автор | Жанр | Статус | Обложка | Рейтинг | Год |
|---|---|---|---|---|---|---|
| Чума | Альбер Камю | Экзистенциализм | прочитано | (ссылка на картинку, необязательно) | 5 | 1947 |

- **Статус** — один из трёх вариантов: `прочитано`, `в процессе`, `хочу прочитать`
- **Рейтинг** — число от 1 до 5 (можно оставить пустым)
- **Обложка** — прямая ссылка на изображение (необязательно; если её нет — покажется цветной корешок-заглушка с названием)
- **Год** — год издания, используется для сортировки (необязательно)

## 2. Опубликуй таблицу как CSV

1. В Google Таблице: **Файл → Поделиться → Опубликовать в интернете**
2. Выбери нужный лист и формат **«Значения, разделённые запятыми (.csv)»**
3. Нажми **Опубликовать**, подтверди
4. Скопируй получившуюся ссылку (выглядит примерно так: `https://docs.google.com/spreadsheets/d/e/2PACX-xxxxx/pub?output=csv`)

Важно: эта ссылка делает таблицу публично доступной для чтения любому, у кого есть ссылка. Если в таблице есть личные заметки, которые не должны быть видны — вынеси их на отдельный лист, который не публикуешь.

## 3. Подключи ссылку к сайту

Открой файл `config.js` и вставь скопированную ссылку:

```js
const CONFIG = {
  CSV_URL: "https://docs.google.com/spreadsheets/d/e/2PACX-xxxxx/pub?output=csv",
};
```

## 4. Проверь локально

Любой простой статический сервер подойдёт, например:

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000` в браузере.

(Открыть `index.html` напрямую двойным кликом не получится — браузер блокирует `fetch` для локальных файлов без сервера.)

## 5. Выложи на GitHub Pages

1. Создай новый репозиторий на GitHub и загрузи туда все файлы (`index.html`, `style.css`, `app.js`, `config.js`)
2. В репозитории: **Settings → Pages**
3. В **Source** выбери ветку `main` и папку `/ (root)`
4. Сохрани — через минуту сайт будет доступен по адресу вида `https://твой-логин.github.io/название-репозитория`

После этого любое изменение в Google Таблице (добавил книгу, поменял статус, поставил рейтинг) появится на сайте при следующей загрузке страницы — пересобирать и перезаливать ничего не нужно.

## Структура файлов

```
index.html      — разметка страницы
style.css       — вся визуальная часть
app.js          — загрузка CSV, рендер полок, поиск/сортировка/фильтры, модалка
config.js       — единственное место, которое нужно редактировать (ссылка на CSV)
demo-books.csv  — пример данных для локального теста (необязателен для продакшена)
```

## Если что-то не загружается

Сайт покажет понятную ошибку прямо на странице. Самые частые причины:
- ссылка в `config.js` не на CSV, а на саму таблицу (нужна именно ссылка из «Опубликовать в интернете», заканчивается на `output=csv`)
- таблица не опубликована или доступ ограничен
- в таблице не нашлось колонки «Название» — без неё строка не попадёт в каталог
